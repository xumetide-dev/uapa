# 范围决策

本文记录功能清单的取舍：哪些进入哪个阶段、哪些延后或排除、哪些待确认。状态取值为
已定、待实测、待确认、延后、排除。

| 编号 | 主题 | 决定 | 理由 | 影响 | 状态 |
|---|---|---|---|---|---|
| SD-01 | 首批目标 | v0.1.0 只做五个目标；Cursor、Kiro、CodeBuddy、OpenCode、DSH 延后，每个目标按宿主模块的结构新增 | [ARCH-001](../architecture/ARCH-001-agent-plugin-build-tool.md) 冻结项；首个使用方只用到这五个目标 | 新增目标按[架构 §2](../architecture/architecture.md#2-目录结构) 的步骤增加宿主模块、能力数据与入口源码，并在 `src/config/` 登记目标名与宿主键；构建编排与守卫运行时的接口不变 | 已定 |
| SD-02 | 组件范围 | v0.1.0 只含 skills 与守卫 hooks；agents 与 MCP 放入 v0.2.0；commands 与 rules 暂不列入 | 首个使用方的试点插件只用 skills 与 hooks，其他插件另用 agents 与 MCP，均未使用 commands 与 rules | 01、05～08 模块的 v0.2.0 功能 | 已定 |
