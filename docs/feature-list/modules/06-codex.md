# 06 Codex 目标

构建 `codex:subprocess`。产物文件：`.codex-plugin/plugin.json`、hooks 配置（默认 `hooks/hooks.json`）、
`hooks/uapa-codex.mjs` 与 `skills/`。代码位于 `src/targets/codex/`、
`src/capabilities/codex-subprocess.ts` 与 `src/runtime/entries/codex-subprocess.ts`。宿主事实见
[Codex](../../research/coding-agent-plugin-manifests/codex-plugins.md)；manifest 与 hooks 的加载、输入与输出以
[Codex hooks 源码核对记录](../../research/coding-agent-plugin-manifests/codex-source-review.md)（rust-v0.162.1）为准。
