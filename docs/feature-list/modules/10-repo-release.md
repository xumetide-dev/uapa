# 10 仓库工程与发布

质量检查、测试夹具、包结构与发布。代码位于 `scripts/`、`test/fixtures/`、`package.json`、
`tsconfig*.json` 与 `biome.json`。仓库不配置 CI，检查与发布都在本地运行（ARCH-001）。

| 编号 | 阶段 | 子模块 | 功能名称 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-10-01 | v0.1.0 | 质量检查 | 本地检查入口 | `pnpm check` 依次运行两套 `tsc` 配置、Biome、`node --test` 与功能清单关系检查，任一失败即以非零退出码结束 | — |
| F-10-02 | v0.1.0 | 测试夹具 | 目标比对夹具 | 一份覆盖 v0.1.0 全部组件与守卫检查的源项目夹具，以及五个目标的期望产物；测试构建夹具后逐字比对 | F-03-05 |
| F-10-03 | v0.1.0 | 包结构 | 包入口与安装面 | `package.json` 声明 `bin`、`exports`、`files`、`engines`，不含任何生命周期脚本；生产依赖只有 rolldown、yaml、zod | — |
| F-10-04 | v0.1.0 | 发布 | 发布脚本 | 工作区干净且检查通过后编译 `dist/`，在 main 之上创建含 `dist/` 的发布提交并打 `vX.Y.Z` tag；不推送 | F-10-01, F-10-03 |
| F-10-05 | v0.1.0 | 发布 | 安装冒烟 | 在临时项目中以 git tag 方式安装发布提交，未放行任何构建脚本即安装成功，并能对夹具运行 `uapa build` | F-10-02, F-10-04 |
