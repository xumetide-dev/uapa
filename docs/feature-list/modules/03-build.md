# 03 构建编排

把源项目逐个目标构建为产物：能力检查、组件放置、产物布局、比对与构建报告。代码位于
`src/build/`、`src/capabilities/types.ts` 与 `src/report/`。本模块不包含任何宿主的格式知识：
宿主模块向它提交各自要写出的文件，它负责检查、合并、写出或比对。

| 编号 | 阶段 | 子模块 | 功能名称 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-03-01 | v0.1.0 | 能力检查 | 定义目标能力数据模型 | `TargetCapabilities` 含宿主名与版本、核对日期、出处、组件承载、守卫能力、失败默认行为、默认超时与工具名映射；缺字段时 `tsc` 报错 | — |
| F-03-02 | v0.1.0 | 能力检查 | 构建时检查组件与守卫能力 | 目标不能承载的组件列为跳过；frontmatter 显式写了该目标时失败；守卫 `requires` 中有目标缺失的能力时该目标失败；可降级的决策记为降级 | F-03-01, F-01-05, F-02-03 |
| F-03-03 | v0.1.0 | 目标构建 | 按目标逐个构建 | 每个目标独立生成；一个目标失败不影响其他目标产出；任一目标失败时命令以退出码 1 结束 | F-03-02 |
| F-03-04 | v0.1.0 | 组件放置 | 放置 skills | 适用于该目标的 skills 写入产物 `skills/<name>/`；产物目录就是源项目根目录时不复制 | F-03-03, F-01-04 |
| F-03-05 | v0.1.0 | 产物布局 | 按宿主分目录写出 | 默认每个宿主一个目录，同一宿主的多个目标写入同一目录（设计提案第 9 节）；写入前只清理该目录；JSON 以固定键序、两空格缩进与结尾换行输出 | F-03-03 |
| F-03-06 | v0.1.0 | 产物布局 | 合并布局写出 | 配置把多个宿主指向同一插件目录时写入同一目录；同名文件内容不一致时构建失败并列出文件与目标；只写入生成的文件，不删除目录中的其他文件 | F-03-05 |
| F-03-07 | v0.1.0 | 产物布局 | 按命名空间合并共用的 JSON 文件 | 宿主模块声明为可合并的 JSON 文件（如根 `plugin.json`），除 `extensions` 外的字段必须一致，`extensions` 按命名空间合并；同一命名空间冲突时失败 | F-03-06 |
| F-03-08 | v0.1.0 | 产物比对 | 只比对不写入 | 在内存中生成全部产物并与磁盘上的同名文件比对；不写任何文件；有差异时列出新增与修改的文件并以退出码 1 结束 | F-03-05 |
| F-03-09 | v0.1.0 | 构建报告 | 生成构建报告 | 每个目标写出安装单位与路径、跳过项、降级项、覆盖文件、残余风险与能力数据核对日期，格式与设计提案第 7 节一致 | F-03-03 |
| F-03-10 | v0.1.0 | 构建报告 | 输出终端摘要 | 按目标列出成功或失败，以及跳过、降级、残余风险的数量和报告文件路径 | F-03-09 |
