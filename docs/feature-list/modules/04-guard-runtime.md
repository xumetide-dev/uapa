# 04 守卫运行时

打包进产物、在宿主中运行的代码中与宿主无关的部分，以及打包本身。代码位于 `src/runtime/core/`、
`src/runtime/entries/` 的公共部分与 `src/bundle/`。`runtime/core` 不做 I/O、不引用 Node 类型；
各宿主的决策输出格式在对应的宿主模块中实现。

| 编号 | 阶段 | 子模块 | 功能名称 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-04-01 | v0.1.0 | 换算 | 工具名换算 | 按能力数据的 `toolNames` 把宿主工具名换算为规范名；未映射的工具以 `host:<原名>` 传入；`shell` 的入参换算为 `{ command }` | F-03-01 |
| F-04-02 | v0.1.0 | 换算 | 入参改写的反向换算与降级 | `rewrite` 的 `command` 反向换算为宿主入参；目标不能改写入参时按 `fallbackReason` 拒绝，不放行原始入参 | F-04-01 |
| F-04-03 | v0.1.0 | 子进程入口 | 读取宿主输入 | 从 stdin 读取 JSON 并取出会话 id、工具名与入参；输入无法解析时执行前检查按拒绝输出 | F-04-01 |
| F-04-04 | v0.1.0 | 子进程入口 | 异常收口 | 守卫逻辑抛错时，执行前检查与提示检查按拒绝输出，以退出码 2 结束并在 stderr 写非空原因；停机检查出错时不阻止结束，并在 stderr 写原因 | F-04-03 |
| F-04-05 | v0.1.0 | 子进程入口 | 按会话保存停机门禁计数 | 继续次数以会话 id 为键保存在宿主的插件数据目录，先写临时文件再重命名；宿主没有数据目录时按范围决策 SD-06 处理 | F-04-03 |
| F-04-06 | v0.1.0 | 打包 | 打包子进程入口 | 守卫逻辑、`runtime/core` 与目标入口打包为 ES2022 ESM 单文件；产物只导入 `node:` 内置模块 | F-04-04, F-02-03 |
| F-04-07 | v0.1.0 | 打包 | 打包 hooks 模块的守卫文件 | 守卫逻辑与 `runtime/core` 打包为 hooks 模块旁的单个相对文件；外部导入只保留 `'claude-code'` | F-02-03, F-04-01 |
| F-04-08 | v0.2.0 | 子进程入口 | 执行后检查的异常收口 | 执行后检查出错时按扣留输出，以说明文字替换原输出 | F-04-04, F-02-04 |
