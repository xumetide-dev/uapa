# 11 agy 目标

构建 `agy:subprocess`（Antigravity CLI）。产物文件：根 `plugin.json`（合并布局或指定替代位置时为
`.antigravity-plugin/plugin.json`）、根 `hooks.json`、`hooks/uapa-agy.mjs` 与 `skills/`。代码位于
`src/targets/agy/`、`src/capabilities/agy-subprocess.ts` 与 `src/runtime/entries/agy-subprocess.ts`。
宿主事实见 [agy](../../research/coding-agent-plugin-manifests/agy-plugins.md)，其中文档未写明的行为以
1.3.4 的本地实测与 1.3.5 的容器实测为准。`agy plugin validate` 对结构错误也报通过，不作为宿主校验；
本宿主不实现 `verify`，由 F-11-05 在生成时检查字段。
