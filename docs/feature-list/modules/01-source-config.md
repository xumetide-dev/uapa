# 01 源项目与配置

读取插件作者的源项目：构建配置 `uapa.config.ts`、各类组件与目标覆盖目录。代码位于
`src/config/` 与 `src/source/`。本模块只读源项目，不写文件，不包含任何宿主的格式知识；
组件放置到产物由 [构建编排](03-build.md) 完成。

| 编号 | 阶段 | 子模块 | 功能名称 | 验收标准 | 依赖 |
|---|---|---|---|---|---|
| F-01-01 | v0.1.0 | 构建配置 | 定义构建配置类型与 `defineConfig` | 配置可声明名称、版本、描述、守卫入口、目标列表、各目标选项与产物布局；类型不符时 `tsc` 报错 | — |
| F-01-02 | v0.1.0 | 构建配置 | 加载 `uapa.config.ts` | 以 Node 类型剥离导入；使用不可擦除语法或相对导入缺 `.ts` 扩展名时，报出文件与原因并以退出码 2 结束 | F-01-01 |
| F-01-03 | v0.1.0 | 构建配置 | 校验构建配置 | 未知目标名、重复目标、缺必填字段或未知目标选项时失败，错误给出字段路径 | F-01-02 |
| F-01-04 | v0.1.0 | 组件读取 | 读取 skills | 读取 `skills/<name>/SKILL.md`，校验 frontmatter 的 `name` 与 `description`；目录名与 `name` 不一致时失败 | F-01-03 |
| F-01-05 | v0.1.0 | 组件读取 | 按 frontmatter `targets` 筛选组件 | 组件 frontmatter 的 `targets` 限定适用目标；含未知目标名时失败；未写时适用于所有能承载该组件的目标 | F-01-04 |
| F-01-06 | v0.1.0 | 目标覆盖 | 复制目标覆盖目录 | `targets/<target>/` 中的文件复制到该目标产物并覆盖同名生成文件；每个被覆盖的文件写入构建报告 | F-01-03 |
| F-01-07 | v0.2.0 | 组件读取 | 读取 agents | 读取 `agents/*.md` 与 frontmatter，校验 `name` 与 `description`；支持 `targets` 筛选 | F-01-05 |
| F-01-08 | v0.2.0 | 组件读取 | 读取 MCP 服务器 | 读取 `mcp/servers.json`：本地服务器只含 `command`、`args`、`env`，远程服务器只含 `url`、`headers`，插件根写作 `{pluginRoot}`；其他字段失败 | F-01-03 |
