| `F-01-13` | 读取 MCP 服务器的环境变量声明 | 本地服务器可写 `envVars`：非空的字符串数组，元素匹配 `^[A-Za-z_][A-Za-z0-9_]*$` 且不重复；远程服务器写 `envVars`、元素不合规则或重复时失败，`field` 写到元素，如 `mcpServers.docs.envVars[1]`（SD-40） | ⏳ | |

| `F-06-12` | MCP 服务器的环境变量与占位符 | 本地服务器的 `envVars` 写为 `env_vars`，字段白名单（F-06-05）允许该字段；有本地服务器未声明 `envVars` 时残余风险列出这些服务器，写明 Codex 只向本地服务器传递 `HOME`、`PATH` 等少数变量；服务器的字段含 `${` 时残余风险写明 Codex 按字面传递（SD-40） | ⏳ | |
| `F-11-12` | MCP 服务器的插件根与环境变量 | agy 1.3.5 不展开 MCP `command` 中的 `${extensionPath}` 与 `${PLUGIN_ROOT}`（TA-25），`command` 含 `{pluginRoot}` 的服务器照常列为跳过（F-11-08）；本地服务器继承会话环境，`envVars` 不写入 `mcp_config.json`；服务器的字段含 `${` 时残余风险写明 agy 按字面传递（SD-40） | ⏳ | |
